¿Cómo usar el Escáner?

Guía completa para leer placas y códigos QR con Win Sports

Pasos Rápidos

1

Instala App

Descarga "IP Webcam" u otra app similar en tu smartphone.

2

Conecta Red

Asegúrate que PC y móvil estén en la misma red Wi-Fi.

3

Inicia Stream

Abre la app y presiona "Start Server" para iniciar.

4

Copia URL

Copia la dirección que aparece en la app (ej: http://IP:PUERTO/video).

5

Ejecuta Script

En PowerShell, ejecuta el comando con la URL obtenida.

6

¡Escanea!

Apunta el móvil a los códigos QR o placas para detectarlos.

Comando PowerShell

Ejecuta este comando en PowerShell reemplazando IP y PUERTO:

python .\lector_qr.py --source "http://IP:PUERTO/video"

Ejemplo:

python .\lector_qr.py --source "http://192.168.1.42:8080/video"

Opciones Disponibles

  • --camera 0 - Usar cámara local (índice 0, 1, 2, etc.)
  • --source URL - Usar stream remoto desde URL
  • --image archivo.png - Analizar una imagen estática
  • --output archivo.csv - Guardar resultados en CSV
  • --help - Mostrar toda la ayuda disponible

Funcionalidades Principales

Cámara Local

Usa directamente la cámara del PC

Stream Remoto

Cámara del móvil vía IP Webcam

Análisis Imagen

Escanea fotos estáticas

Exportar CSV

Guarda resultados en Excel

Deduplicación

Evita duplicados automáticamente

Interfaz Web

Panel gráfico intuitivo

Solución de Problemas

  • App no conecta: Verifica que ambos dispositivos están en la misma red Wi-Fi
  • No se detecta código: Intenta acercarte más o cambiar el ángulo de la cámara
  • URL no funciona: Prueba copiar la URL en el navegador primero
  • PowerShell no reconoce comando: Asegúrate de tener Python instalado y el virtualenv activado
